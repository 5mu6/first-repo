## SizeFit 尺码助手

[`sizefit/`](sizefit/) is a browser tool for buying clothes from Chinese sellers (Taobao, Tmall, 1688, Weidian and agent sites). It reads the item's size chart from a screenshot, pasted text or a one-click browser helper. It converts the Chinese measurements and units (cm, 市尺/寸, 斤, flat-lay 平铺 halves), recommends the size that fits your measurements, and draws that size on a figure built to your proportions.

See [sizefit/README.md](sizefit/README.md) for how to use it, and run `npm test` for the tests.
